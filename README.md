# Viewly — Content Discovery Website

Viewly is a front-end website concept for discovering content from different categories and exploring featured items through a simple interface.

## ✨ Features

- Popular content categories
- Featured content cards
- Search and filter content by text
- A message when no matching content is found
- A "Start Exploring" button that scrolls to the categories section

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## 📂 Project Structure

```text
Viewly/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/hsanrze2006/Viewly.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation is required.
